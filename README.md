# Task Management System

A simple and user-friendly Task Management System developed using React.js.

## Features
- User Registration and Login
- Forgot Password
- Add, Edit and Delete Tasks
- Task Category Management
- Filter Tasks by Status
- Export Tasks
- User Authentication

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Local Storage

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vanmathi-creator/Task-Management-System.git
   ```

2. Navigate to the project folder:
   ```bash
   cd Task-Management-System
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the project:
   ```bash
   npm run dev
   ```
